# Anas Hamandoush — Interactive Portfolio

موقع معرض أعمال تفاعلي ثابت، جاهز للنشر مباشرة على GitHub Pages.

## تشغيل الموقع

افتح ملف `index.html` مباشرة بالمتصفح، أو شغّله من VS Code باستخدام إضافة Live Server.

## أين أعدّل؟

- **الاسم، الوصف، روابط التواصل، ترتيب المشاريع والصور:** داخل `portfolio-data.js`.
- **ألوان الموقع:** في بداية `styles.css` ضمن المتغيرات الموجودة تحت `:root`.
- **اللون الأحمر الأساسي:** المتغير `--accent`.
- **الصور:** داخل `assets/images`، ويمكن استبدال أي صورة مع الإبقاء على اسمها نفسه.
- **التكوين والحركات:** داخل `styles.css` و`script.js`.

## إضافة روابط التواصل

افتح `portfolio-data.js` وعدّل القيم التالية:

```js
"email": "your@email.com",
"instagram": "https://instagram.com/username",
"behance": "https://behance.net/username"
```

اترك أي رابط فارغًا لإخفائه من الموقع.

## رفعه على GitHub Pages

1. أنشئ مستودعًا جديدًا على GitHub.
2. ارفع **محتويات هذا المجلد نفسها** إلى جذر المستودع، وليس المجلد الخارجي المضغوط.
3. فعّل GitHub Pages للمستودع واختر النشر من الفرع الرئيسي ومجلد الجذر.
4. بعد النشر سيظهر رابط الموقع ضمن إعدادات Pages.

## ملاحظات

- لا يحتاج الموقع إلى قاعدة بيانات أو استضافة مدفوعة.
- جميع الصور مضغوطة بصيغة WebP بجودة عالية لتسريع التحميل، من دون قص الأعمال أو تغيير تكوينها.
- الموقع متجاوب مع الموبايل والكمبيوتر، ويدعم فتح الأعمال بعارض صور كامل والتنقل بالأسهم ولوحة المفاتيح.
