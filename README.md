**للتحديث على GitHub Pages:** ارفع الملفات المعدلة إلى جذر المستودع واستبدل الملفات القديمة. لا ترفع ZIP نفسه. بعد الـCommit انتظر اكتمال Pages ثم افتح الموقع مع تحديث قسري Ctrl+F5.

# معرض أعمال Anas Hamandoush — النسخة العربية

موقع معرض أعمال تفاعلي ثابت، جاهز للرفع على GitHub Pages، بتصميم أسود وأحمر واتجاه عربي RTL.

## الملفات الرئيسية

- `index.html` — بنية الصفحة والنصوص الثابتة.
- `styles.css` — الألوان، الخطوط، الحركات والتجاوب.
- `portfolio-data.js` — الاسم، وصف المصمم، المشاريع، أسماء الأعمال وروابط التواصل.
- `script.js` — الفلاتر، معرض الصور، الـLightbox والحركات التفاعلية.
- `assets/images/` — صور الأعمال.

## تعديل البيانات

افتح `portfolio-data.js` وعدّل الحقول في `PORTFOLIO_CONFIG`.

لإظهار روابط التواصل، أضف القيم داخل:

- `email`
- `instagram`
- `behance`

## تغيير اللون الأحمر

افتح `styles.css` وعدّل:

```css
--accent: #ff2d2d;
--accent-deep: #b50000;
```

## الرفع على GitHub Pages

ارفع **محتويات هذا المجلد نفسها** إلى جذر المستودع، بحيث يكون `index.html` ظاهرًا مباشرة في الصفحة الرئيسية للمستودع، وتأكد أن `assets` مجلد حقيقي وداخله `images`.

ثم من:

`Settings → Pages → Deploy from a branch → main → /(root)`
